# PM Portfolio Website

A professional Product Management portfolio built with Lovable to showcase my experience, certifications, and product projects.

## Overview

The website includes four public sections:

- **My Story** — Professional background and transition into Product Management.
- **Experience** — Career timeline with expandable details.
- **Certifications** — Credentials, descriptions, and verification links.
- **PM Projects** — Project cards linking to case studies, prototypes, demos, and repositories.

## Admin Dashboard

A private admin dashboard allows the portfolio owner to manage content without editing code.

Planned capabilities include:
- Secure owner authentication.
- Create, edit, reorder, publish, and unpublish content.
- Upload certificates, project images, and supporting documents.
- Manage project links and preview changes before publishing.

## Design Principles

- Clean, ChatGPT-inspired visual language.
- Subtle color accents on context cards.
- Accessible typography and responsive layouts.
- Reusable components and maintainable content structures.

## Technology

- **Website builder:** Lovable
- **Backend:** Lovable Cloud, subject to implementation
- **Version control:** GitHub

## Project Status

Initial development. Features and integrations will be documented as they are implemented and tested.

## Security

Never commit passwords, API keys, environment files, or other secrets. Administrative access and uploaded files must be protected by appropriate backend permissions.

## Product Goal

Make the portfolio easy for recruiters to explore and easy for its owner to update as new projects and certifications are completed.
